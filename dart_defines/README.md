# dart_defines

Танзимоти ҳангоми сохтан (`--dart-define-from-file`).

## ad_units.json

Шиносаҳои ҷойгиршавии рекламаи Yandex барои build-и **release**.

Ин файл **сир нест**. Шиносаи ҷойгиршавӣ дар ҳар APK-и кушодашуда
дида мешавад ва барои дуздидан фоида надорад — он танҳо мегӯяд, ки
реклама ба кадом ҳисоб тааллуқ дорад. Барои ҳамин ӯ дар repository
нигоҳ дошта мешавад, на дар GitHub Secrets.

Сабаби дигар муҳимтар аст: агар шиноса дар Secrets бошад ва касе онро
нагузорад, build бе хатогӣ мегузарад ва реклама хомӯш мемонад —
маҳз ҳамин хатои хомӯш пештар рӯй дод. Дар файли repository чунин
шуда наметавонад: тест ва худи build онро месанҷанд.

**Сир** (калиди имзо, ADS_CALLBACK_SECRET, AGORA_APP_ID) ҳеҷ гоҳ
ин ҷо гузошта намешавад.

### Ҳолати ҳар шиноса

| Шакл | Шиноса | Ҳолат |
|---|---|---|
| `interstitial` | `R-M-19230220-1` | Дар дастгоҳ санҷида шуд: ҷойгиршавӣ ҳаст. «No ads available» ҷавоби inventory аст, на хатои танзим. |
| `rewarded` | `R-M-19230220-2` | Соҳиби барнома дар кабинети Yandex сохт (15.09.2026). Дар дастгоҳ ҳанӯз санҷида НАШУДААСТ. |
| `banner` | `R-M-19230220-3` | Аз танзимоти пештара гирифта шуд. Дар экрани ташхис санҷида нашудааст. |
| `native_feed` | `R-M-19230220-4` | Ҳамон ҷо. Санҷида нашудааст. |

Ду сатри охир аз коди пештара (пеш аз он ки шиносаҳо ба build
гузаранд) омадаанд. Онҳо сохта нашудаанд, вале тасдиқ ҳам
нашудаанд — экрани ташхис (Танзимот → Ташхиси реклама) дар build-и
release ҳолати ҳақиқии ҳар чорро нишон медиҳад.

### Истифода

```bash
flutter build appbundle --release \
  --dart-define-from-file=dart_defines/ad_units.json
```

Дар CI ин ду workflow онро медиҳанд:

- `.github/workflows/release.yml` — AAB-и имзошуда барои Google Play
- `.github/workflows/flutter_full_build.yml` — APK + AAB

`test/ad_units_file_test.dart` месанҷад, ки ҳар workflow-и release
ин файлро медиҳад. Агар қадами нави build илова шавад ва файл фаромӯш
шавад, тест меафтад.
