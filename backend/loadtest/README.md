# Санҷиши бор

⚠️ **Танҳо ба муҳити САНҶИШӢ.** Генератор ба production равона
намешавад (суроғаҳои маълуми production рад карда мешаванд), вале
масъулият бар зиммаи иҷрокунанда аст: он маълумотро тағйир медиҳад.

## Тайёрӣ

Базаи ҷудогона ва маълумоти СИНТЕТИКӢ (ҳеҷ маълумоти воқеӣ):

```sql
CREATE DATABASE raonson_load;
-- корбарони синтетикӣ: username LIKE 'load_u%'
INSERT INTO users(username, email, password)
SELECT 'load_u'||i, 'load_u'||i||'@test.invalid', 'x'
FROM generate_series(1, 50000) i;
```

Сервер бо ҳамон база:

```
DATABASE_URL=postgres://.../raonson_load JWT_SECRET=... ./raonson
```

## Иҷро

```
# Трафики воқеӣ: корбарон бо таваққуф (пешфарз 2 с)
go run ./loadtest -url http://localhost:8099 \
  -db "$DATABASE_URL" -secret "$JWT_SECRET" \
  -users 500 -dur 20s -think 2s

# Ҳадди ниҳоии гузарониш: бе таваққуф, маҳдудият баланд
RATE_LIMIT_MULTIPLIER=100 ./raonson   # дар сервер
go run ./loadtest ... -users 50 -think 0

# Як роҳ (спайк)
go run ./loadtest ... -only feed -think 0
```

## Ду чиз чен мешавад

| Ҳолат | Чӣ маъно дорад |
|---|---|
| `-think 2s` | **корбарони ҳамзамон** — чанд нафар барномаро якбора истифода бурда метавонанд |
| `-think 0` | **гузарониш (RPS)** — ҳадди сервер |

Инҳоро омехта накунед: 1000 корбари ҳамзамон 1000 RPS нест.

## Маҳдудият

Генератор ва сервер дар ЯК мошин кор мекунанд. Аз ~1000 goroutine
худи генератор процессорро мегирад ва натиҷа дигар ба сервер тааллуқ
надорад (`/proc/loadavg`-ро тафтиш кунед). Барои санҷиши воқеан
калон генераторро ба мошини ҷудогона гузоред.
