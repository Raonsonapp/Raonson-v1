# Анализи пайвасти барнома ↔ сервер

Санаи анализ: 2026-09-22 · усул: **мошинӣ**, на аз рӯи хотира.

Ин ҳуҷҷат аз `docs/INSTAGRAM_PARITY.md` фарқ мекунад. Он ҷо саволи
«кадом функсия ҳаст?» буд. Ин ҷо саволи дигар аст:

> Он чи навишта шудааст, воқеан ба ҳам **пайваст** аст?

Чунки бузургтарин камбудии барнома ҳамин буд: код ҳаст, вале аз
барнома ба он роҳ нест. Корбар мегӯяд «функсия кор намекунад» —
ва ҳақ аст, гарчанде код бехато навишта шудааст.

---

## Усул

Се санҷиши мошинӣ гузаронда шуд:

1. **Ҳар дархости барнома → оё дар сервер чунин роҳ ҳаст?**
   Ҳамаи сатрҳои `/...`-и Dart ҷамъ карда шуданд ва бо ҷадвали
   пурраи роҳҳои Gin муқоиса шуданд (бо назардошти гурӯҳҳо:
   `r.Group("/posts")` + `po.POST("/:id/like")` → `/posts/:id/like`).

2. **Ҳар роҳи сервер → оё барнома онро даъват мекунад?**

3. **Ҳар экран → оё аз ягон ҷо кушода мешавад?**

---

## 1. Дархостҳои барнома, ки дар сервер нестанд

**Ҳеҷ як.** Ҳамаи 169 роҳи даъватшаванда дар сервер мавҷуданд.

Ин натиҷаи хуб аст ва бояд ҳамин тавр гуфта шавад: «404-и пинҳонӣ»
вуҷуд надорад.

---

## 2. Роҳҳои сервер, ки барнома ҳеҷ гоҳ даъват намекунад

Аз 298 роҳ, баъди тоза кардани натиҷаҳои бардурӯғ (роҳҳое, ки дар
Dart аз пораҳо сохта мешаванд — `'/posts/$id/collab/${accept ? ...}'`),
инҳо ВОҚЕАН истифода намешаванд:

| Роҳ | Чист |
|---|---|
| `/discover/people` | тавсияи одамон дар «Кашф» |
| `/discover/trending` | мавзӯъҳои дар авҷ |
| `/gifts/received` | тӯҳфаҳои гирифташуда |
| `/effects/mine` | эффектҳои худи корбар |
| `/creator/insights`, `/creator/analytics` | омори муаллиф |
| `/likes/:targetId` | рӯйхати лайкҳо аз роҳи умумӣ |
| `/ai/moderate` | тафтиши мазмун |

Инҳо хатои ҷиддӣ нестанд — қисми зиёдашон такрори роҳи дигаре
доранд, ки барнома истифода мебарад (масалан `/posts/:id/likes`).
Вале онҳо қарзи техникӣ мебошанд: касе онҳоро нигоҳ медорад, ҳеҷ
кас истифода намебарад.

Роҳҳои `webhook`, `/p/:id`, `/r/:id` дар ин рӯйхат нестанд — онҳо
барои сервери дигар ва браузеранд, на барнома.

---

## 3. Экранҳое, ки аз барнома кушода намешуданд

### 3.1 Live — пахши зинда ✅ ислоҳ шуд

`lib/live/live_screens.dart` — 420 сатр, Agora + сервер
(`/live/`, `/live/:id/join`, `/live/:id/comment`, …). Ҳама тайёр.

**Вале ба `LiveListScreen` аз ҳеҷ ҷо роҳ набуд.** На тугма, на
сабт дар `app_controller.dart`. Функсия вуҷуд дошт ва ба корбар
намерасид.

Ислоҳ: дар менюи сохтан (поёни галерея) tab-и чорум —
`Публикатсия | Сторис | Reels | Live`, маҳз мисли Instagram.

### 3.2 Тасдиқи почта ✅ сохта шуд

`EmailVerifyScreen` ва `OtpVerifyScreen` мавҷуд буданд, вале **чор**
камбудӣ доштанд якбора:

1. аз ҳеҷ ҷо кушода намешуданд;
2. `AppRoutes.otpVerify = '/otp-verify'` эълон шуда буд, аммо дар
   `onGenerateRoute` **case надошт** — ҳар кӣ ба он мерафт, экрани
   ВУРУДро мегирифт;
3. онҳо ба `/auth/verify-email` ва `/auth/verify-otp` муроҷиат
   мекарданд — **ин ду роҳ дар сервер вуҷуд надоштанд**;
4. `ApiClient.post` ҳангоми 400/401 хато **намепартояд** — Response
   бармегардонад. Пас `try { post() } catch` ҳеҷ гоҳ кор намекард ва
   **рамзи НОДУРУСТ ҳам «тасдиқ» мешуд**.

Ҳамаи чор ислоҳ шуданд:

* сервер: `backend/handlers/verify_email.go` — рамз ба почта, калид
  ба ҳисоб баста (`otp:email:<uid>:<email>`), як рамз як бор, почтаи
  ҳисоби дигар гирифта намешавад;
* база: `users.email_verified` (ин бо сутуни `verified`, яъне
  аломати кабуд, ҳеҷ алоқа надорад);
* барнома: роҳҳо дар `app_controller.dart`, даромадгоҳ дар
  «Танзимот → Амният», матн дар ҳар се забон;
* ҳарду экран акнун `statusCode`-ро месанҷанд.

Инфрасохтори фиристодан аллакай буд:
`backend/utils/otp_sender.go` (Brevo, SMTP, SMS, WhatsApp, Telegram).

### 3.3 Нусхаи дуюми `AppRoutes` ✅ нест карда шуд

`lib/navigation/route_guards.dart` синфи дуюми `AppRoutes`-ро бо
қиматҳои **ДИГАР** дошт (`otpVerify = '/otp'` ба ҷои
`'/otp-verify'`). Он аз ҳеҷ ҷо import намешуд — вале агар касе
тасодуфан онро мегирифт, ҳамаи роҳҳои барнома вайрон мешуданд.

---

## Он чи ин анализ НАМЕГӮЯД

Ин санҷиш **сохтори** пайвастҳоро мебинад, на кори онҳоро. Он
намегӯяд:

* оё ҷавоби сервер дуруст аст;
* оё тугма баъди зер шудан чизе мекунад;
* оё видео мехонад;
* оё огоҳинома мерасад.

Барои ин ду чизи дигар лозим аст: тести эмулятор
(`integration_test/app_smoke_test.dart`) ва телефони воқеӣ.

---

## Санҷише, ки ин камбудиҳоро дигар намемонад

`test/wiring_test.dart` — 8 санҷиш:

* ҳар экрани муҳим аз ҷои дигар кушода мешавад (Live, тасдиқи почта);
* ҳар сатри `AppRoutes` дар `app_controller` case дорад;
* `AppRoutes` танҳо ЯК ҷо эълон шудааст;
* экранҳо `statusCode`-и ҷавобро месанҷанд;
* калидҳои тарҷума дар ҳар се забон ҳастанд.

Дар сервер: `backend/handlers/verify_email_test.go` — regexp-и почта,
бастани калид ба ҳисоб, сабти роҳҳо дар router бо вуруди ҳатмӣ,
мавҷудияти сутун дар `schema.sql`.

Ин санҷишҳо матни кодро мехонанд, на барномаи зиндаро. Онҳо
«пайваст ҳаст»-ро тасдиқ мекунанд, на «кор мекунад». Барои дуюмӣ
тести эмулятор ҳаст.
