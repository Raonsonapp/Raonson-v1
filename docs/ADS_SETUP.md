# Танзими реклама ва галочка

## Савол: «оё реклама нишон дода мешавад?»

Дар барнома: **Танзимот → Санҷиши реклама** (танҳо барои @raonson).

Он ҷо чор чиз дида мешавад:

| Чӣ | Маънои «сабз» |
|---|---|
| SDK | Yandex SDK оғоз шуд |
| Interstitial / Rewarded | реклама бор шуд ва тайёр аст |
| Хато | матни ВОҚЕИИ хатои Yandex (масалан «No fill») |
| Ҳисоби сервер | нишондиҳӣ ба галочка меравад ё не |

Тугмаи «Нишон додан» рекламаро мекушояд. Барои Rewarded пас аз
тамошо экран мегӯяд:

- **«Сервер ҳисоб кард»** — ҳама чиз кор мекунад;
- **«Сервер ҳисоб НАКАРД»** — реклама баромад, вале callback нарасид.

Ин фарқ муҳим аст: реклама нишон додан ва ҳисоб шудан ДУ чизи ҷудост.

## Чаро реклама метавонад набарояд

Аксаран сабабҳо ин ҷо, на дар код:

- **No fill** — Yandex барои ин ҷойгиршавӣ реклама надорад. Дар
  аккаунти нав ин муқаррарист; чанд рӯз лозим аст.
- **Ҷойгиршавӣ фаъол нест** — дар кабинети Yandex тасдиқ нашудааст.
- **Барнома дар кабинет сабт нашудааст** (bundle id мувофиқ нест).
- **Шабака нест** ё VPN.

Матни дақиқ дар экрани ташхис менамояд.

## Танзими ҳисоб (S2S rewards)

Бе ин реклама нишон дода мешавад, вале **ба галочка намеравад**.

### 1. Сирр дар сервер

```
ADS_CALLBACK_SECRET=<сатри тасодуфии дароз>
```

Бе он ҳисоб умуман кор намекунад — қасдан. Галочка 20 сомонӣ
меарзад; агар сервер ба сухани телефон бовар кунад, ҳар кас бо чанд
дархости `curl` онро ройгон мегирад.

### 2. Кабинети Yandex

Дар танзимоти ҷойгиршавии **Rewarded** → Server-side rewards:

```
URL:  https://<домени шумо>/ads/callback
```

Параметрҳое, ки бояд фиристода шаванд:

| Параметр | Аз куҷо |
|---|---|
| `user_id` | аз `parameters` -и дархост (барнома онро мефиристад) |
| `transaction_id` | нишони беназири нишондиҳӣ |
| `timestamp` | вақти Unix |
| `signature` | HMAC-SHA256 бо ҳамон сирр |

**Имзо чӣ тавр ҳисоб мешавад:** ҳамаи параметрҳо ба ғайр аз
`signature` аз рӯи алифбо тартиб дода мешаванд, ҳамчун `k=v` бо `&`
пайваст мешаванд, ва HMAC-SHA256 бо сирр гирифта мешавад (hex).

Мисол:
```
ad_network=yandex&timestamp=1757846400&transaction_id=abc&user_id=u1
```

### 3. Санҷиш

```bash
# Дархости БЕ имзо бояд 403 диҳад:
curl -i "https://<домен>/ads/callback?user_id=u1&transaction_id=t1&timestamp=$(date +%s)"
```

Агар 403 наояд — сирр гузошта нашудааст ё роҳ нодуруст аст.


## Шиносаҳои ҷойгиршавӣ (ad unit ID)

### Ҳолати имрӯза — аз ташхиси ВОҚЕИИ дастгоҳ

| Шакл | Шиноса | Натиҷа |
|---|---|---|
| Interstitial | `R-M-19230220-1` | «no ads available» — ҷойгиршавӣ **ҲАСТ**, вале ҳоло реклама надорад |
| Rewarded | `R-M-19230220-2` | «AdUnitId does not exist» — ҷойгиршавӣ **НЕСТ** |

Фарқ муҳим аст: якум масъалаи захира (inventory) аст ва худ аз худ
ҳал мешавад; дуюм хатои танзим аст ва бояд дар кабинети Yandex
сохта шавад.

### Чӣ тавр кор мекунад

- **debug** — шиносаҳои РАСМИИ демои Yandex
  (`demo-rewarded-yandex` ва ғ.). Онҳо ҳамеша реклама медиҳанд.
- **release** — шиносаи ВОҚЕӢ, ки ҳангоми сохтан дода мешавад.

Дар код ҳеҷ шиносаи production нест ва ҳеҷ гоҳ ба демо намеафтад:
рекламаи демо ба корбари воқеӣ даромад намедиҳад, вале «кор мекунад»
менамояд — хатои хомӯш.

Агар шиноса дода нашавад, ҳамон шакл ХОМӮШ мемонад ва экрани ташхис
«not configured» мегӯяд.

### Сохтани build-и production

Шиносаҳо дар `dart_defines/ad_units.json` мемонанд ва ҳангоми сохтан
дода мешаванд:

```bash
flutter build appbundle --release \
  --dart-define-from-file=dart_defines/ad_units.json
```

Ҳар ду workflow-и release (`release.yml` ва `flutter_full_build.yml`)
ин файлро медиҳанд. `test/ad_units_file_test.dart` месанҷад, ки ҳеҷ
қадами build онро фаромӯш накардааст — пештар маҳз `release.yml`
(AAB барои Google Play) ҳеҷ `--dart-define` намедод.

Чаро дар repository, на дар GitHub Secrets: шиноса сир нест (дар ҳар
APK дида мешавад), вале агар он дар Secrets бошад ва касе онро
нагузорад, build бе хатогӣ мегузарад ва реклама хомӯш мемонад. Ниг.
`dart_defines/README.md`.

### Ҳолати ҳар шиноса

| Шакл | Шиноса | Дар дастгоҳ санҷида шуд? |
|---|---|---|
| Interstitial | `R-M-19230220-1` | Ҳа — ҷойгиршавӣ ҳаст, вале inventory нест |
| Rewarded | `R-M-19230220-2` | НЕ — нав сохта шуд, санҷиш лозим |
| Banner | `R-M-19230220-3` | НЕ |
| Native feed | `R-M-19230220-4` | НЕ |

Экрани ташхис (Танзимот → Ташхиси реклама) дар build-и release
ҳолати ҳақиқии ҳар чорро нишон медиҳад.

### Барои Rewarded чӣ бояд кард

1. ✅ Дар кабинети Yandex ҷойгиршавии **Rewarded** сохта шуд:
   `R-M-19230220-2`.
2. ✅ Он дар `dart_defines/ad_units.json` гузошта шуд.
3. ⬜ Дар ҳамон ҷойгиршавӣ **S2S rewards**-ро танзим кунед (ниг. боло).
4. ⬜ `ADS_CALLBACK_SECRET`-ро дар HuggingFace Space → Settings →
   Secrets гузоред. То он вақт callback-и Yandex бо 403 рад мешавад
   ва мукофот дода намешавад.
5. ⬜ Build-и release-ро дар дастгоҳи воқеии Android санҷед.

## Зинаҳо

| Реклама | Мӯҳлат |
|---|---|
| 300 | 3 рӯз |
| 600 | 1 ҳафта |
| 1200 | 1 моҳ |

Корбар ҳадафро худаш интихоб мекунад; ҳангоми расидан галочка
ХУДКОР дода мешавад.

Танзим: `ADS_TIER_3D`, `ADS_TIER_7D`, `ADS_TIER_30D`.

### ⚠️ Ҳадди рӯзона

`ADS_DAILY_CAP` (пешфарз 200) — аз он зиёд дар як рӯз ҳисоб
намешавад.

Ин маънои онро дорад, ки зинаи 300 дар як рӯз пур намешавад — ҳадди
ақал ду рӯз лозим аст. Ин **қасдан** аст: шабакаҳои реклама ҳаҷми
зиёдро ҳамчун трафики бардурӯғ мешуморанд ва аккаунтро маҳдуд карда
метавонанд.
